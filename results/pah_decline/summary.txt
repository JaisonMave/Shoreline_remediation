Notes and departures from the plan (all recorded in processing_log.txt):
1. Organic matter, bulk density and salinity are measured on none of the PAH samples (different Sample_IDs), so the Tobit used the one
   soil property measured on the same samples, total organic carbon (ASSUMED substitute for organic matter), with campaign. Depth class was
   not used in the Tobit (too few deeper samples). A run with every non-detect set to half the proxy limit (the plan's fallback) is in sensitivity.csv.
2. Individual alkyl isomers contained in homologue-group rows were removed by name before summing to avoid double counting (58 compounds kept).
3. Reading the hopane outcome: the verdict rule is about error against M0. For the ratio, M1 beats M0 with a NEGATIVE k (the ratio rises over
   time, pooled half-life undefined), so "validated" there means a rise was predicted better than no change, not a decline.
4. By state: errors only (by_oiling_class.csv, stratum_type = state); no state-specific half-life was fitted.
5. Oiling classes with few stations (very_light 10) have wide intervals; 56 stations are "unknown" (no SCAT zone within 100 m).
