# F11 expert review pack

## Purpose and status

This pack contains ten fixed, traceable pipeline reports for independent review. It is not an expert elicitation result: **no reviewer responses have been supplied or invented**. Four reports reproduce the F9 examples; six span marsh, mangrove, sand, bedrock and cobble scenarios and oiling classes.

## Files

All reports are JSON in `results/f11_validation/reports/`. Each records inputs/assumptions, scope tier, recommendation class per option, constraints, evidence and trace.
