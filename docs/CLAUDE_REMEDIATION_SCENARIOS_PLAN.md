# Natural recovery and remediation scenarios for three shoreline outcomes

Implementation plan for Claude Code | 21 November 2026 | Starting revision `6842911` on `codex/scenario-prediction-plan`

## What a user should be able to do

Run the existing Assessment, open **Explore future scenarios**, and select a response technique. See natural recovery alongside that technique for **total vegetation cover**, **soil PAH concentration** and **cumulative shoreline retreat**. Each outcome shows the strongest result the site evidence supports: observed time series, comparable field contrasts, an admitted model trajectory, a user-defined sensitivity scenario, or a specific evidence gap. Changing the technique updates all three outcomes together. Changing a research assumption never recalculates a recommendation.

Start with heavily oiled Bay Jimmy marsh because the repository already links untreated and treated plots to field measurements there. Here, “baseline” means **oiled shoreline left to natural recovery**. The nearby unoiled plots provide ecological context. Statistical benchmarks such as persistence and B1 serve model evaluation. The design should accept additional sites when their evidence is documented. Rocky and mangrove runs should continue to return their own screening results and scope limitations.

## 3. Provide a numerical what-if mode for allowable techniques

This gives planners a way to explore an unstudied technique without first obtaining a fitted treatment coefficient. For each allowed arm with a defensible starting observation, let the user specify an intervention date, effect duration and endpoint-specific assumptions. Leave treatment-effect inputs blank until explicitly supplied. Carry the same environment, baseline parameters and pre-intervention history through both arms. The branches meet at intervention unless an explicit instantaneous change is part of the assumption.

- **Cover:** accept a user-specified change in recovery rate or a bounded, time-limited cover shift in percentage points. Declare whether and when it persists, fades or ceases. Enforce 0–100% and explain impossible inputs. A year-two field difference supplies one historical comparison; applying it each year would misrepresent the study.
- **PAH:** require a compatible starting concentration, reference rate and, if used, background concentration. For example, an explicit one-time removal fraction reduces the removable amount at intervention; an independently specified decay rate governs subsequent decline. Distinguish surface oil removal from a measured change in soil concentration. An entered removal fraction for soil is an assumption requiring its own provenance.
- **Retreat:** reuse piecewise integration in actual elapsed years. Apply an explicitly assumed change in m/year over the specified period. Allow an intervention to worsen retreat. Export both cumulative retreat and the paired difference in metres. Resetting the existing shoreline position when a rate changes creates a spurious instantaneous gain.

Represent manual inputs as `user_assumption` with units, origin, support and affected endpoint. Display “User-defined what-if” on the figure and in downloads. Missing baseline, missing assumed coefficient or incompatible units produce an explicit unavailable outcome. A user may set zero as a deliberate neutral scenario. Do not fill every technique with the same default effect. Keep assumption-driven deltas outside treatment ranking, reported benefit and promotion.

**Acceptance:** zero effect reproduces baseline exactly; an adverse effect retains its sign; an off-grid change date is integrated correctly; annual and monthly results agree at shared dates; no pre-intervention differences; exports identify which parameters came from the user. A 2030/2050 plot exposes its assumptions even when viewed without the dashboard.

## 4. Compare process and statistical workflows under a written validation protocol

Run this track per endpoint and technique as data become available. Write the intended claim, target unit, target horizon, training/evaluation split, minimum useful improvement and uncertainty criteria **before** fitting.

1. **Process-model audit.** Inspect `shoreline_transport.simulate_transect`, `process_model.TREATMENT_PARAMETERS`, `models/process_model_v2.json` and the F5 record. Map report option keys to supported process-model keys with an explicit allowlist. The legacy simulator falls back to `no_cleanup` for an unknown treatment string. The adapter must intercept an unmapped key and return a reason. Mark assumed removal/disturbance coefficients. Treat residual oil mass as an intermediate output. A soil mass/depth and analyte mapping is needed for tPAH; vegetation response and geomorphic erosion each need their own observed transfer relationship. Keep existing F5 results intact (calibrated 0.775 vs empirical 0.750).
2. **Start with the simplest statistical benchmark.** For each endpoint compare the models in section 2 on the same observations. Fit a hierarchical or mixed-effects model only when plot/site replication and repeated observations support it. Consider ML residual correction of a process prediction as a challenger only with enough independent treatment/site groups. Train the correction on out-of-fold process predictions. Avoid training on synthetic scenario outputs, report labels or the same field contrasts later used to score it.
3. **Identify treatment effects.** Inventory treatment start, method, intensity, access and oiling severity before intervention, exposure and follow-up on comparable untreated units. With credible pre-treatment histories and an appropriate comparison group, evaluate a before/after control-impact design and its assumptions. Otherwise retain descriptive or conditional claims. Random plot-level splits across repeated measurements will leak site history.
4. **Hold out the right units.** Use time-forward cutoffs for horizons, whole plots for within-site checks and whole sites/spills for transfer. Keep paired arms, plots reused in multiple papers, preprocessing and tuning inside their proper split. Score cover MAE/bias in percentage points, PAH error on a prespecified concentration/log scale, and retreat MAE/bias in metres by lead. Evaluate treatment-minus-baseline differences where independent comparators exist. Report sample counts, interval coverage/width, subgroup failures and unsuccessful fits. Historical P-RET-1's 0.5 m criterion applies to its specific retreat experiment.
5. **Decide admission.** Keep fitted models experimental until the registry's promotion requirements and the comparison layer's target, mechanism, discrepancy, independence and gate checks are met. Record a reason if a simpler baseline wins or the test is unevaluable. Promotion applies only to the tested endpoint, technique, population and horizon. Human review and source verification retain their actual status.

**Acceptance:** deliver a reproducible protocol, source inventory, benchmark table and per-candidate verdict. When suitable data do not exist, deliver a precise acquisition request (fields, units, dates, needed comparison group and independent site) and continue with the historical and what-if modes.

## 5. Design the plots in the existing Assessment experience

Extend `ui_future_scenarios.py` in place. The live report supplies the selector and its conditions. Keep one natural-recovery reference visible, then compare one technique by default. Allow a second eligible technique for sensitivity comparisons. Use the existing Altair/Streamlit theme and page navigation.

- **Composition:** a compact technique selector and assumption summary, followed by three aligned small multiples on desktop, stacked vertically on mobile. Each panel has an endpoint title, units on the y-axis, a direct series label, the last supported date and a one-line takeaway. Keep scales independent across incompatible units. Share the calendar axis when meaningful; provide an evidence-window view so two PAH observations remain legible beside a 2050 retreat scenario.
- **Visual language:** baseline in the existing pale highlight, treatment in teal or blue. Also distinguish by shape and dash for colour-vision accessibility. Field observations are points, supported fits are solid, conditional continuations dashed. Mark the intervention and endpoint-specific evidence cutoff. Use sparse grids and direct end labels; avoid smooth interpolation across missing observations or discrete treatment jumps.
- **Differences:** add a compact effect plot only when outcome, unit, date, population and comparator match. Use a zero line and clearly label the sign (e.g., positive cover gain or metres of retreat avoided). Distinguish a field confidence interval, model prediction interval and user sensitivity range in tooltips. Include method, level, validation and scope for each interval. Render gaps as a short explanation plus available observations.
- **Accessible delivery:** keyboard-operable controls, descriptive chart alt text and a tabular alternative. Supply a replayable JSON, tidy CSV and publication-readable PNG/SVG of each comparison with embedded units, site, comparator, support dates and scenario status. Keep the existing assessment/report downloads working.

**Acceptance:** render Bay Jimmy manual removal, a prerequisite-blocked technique, an allowable technique with no measured effect, and an unsupported habitat.
